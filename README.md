# Bounce Hero — Public Play Build

이 저장소는 **Bounce Hero의 GitHub Pages 배포 전용 저장소**입니다.

## Play

### [Bounce Hero 플레이](https://rurulala498.github.io/bounce-hero/)

PC Chrome과 16:9 화면을 우선 지원합니다.

## Controls

| 입력 | 동작 |
| --- | --- |
| `←` / `→` | 좌우 이동 |
| `↑` | 체공당 1회 Air Jump |
| `←←` / `→→` | Double Tap Dash |
| `Space` | 공중 Dive |
| `Q W E R` | Active Skill Slot 1~4 |
| `A S D F` | Active Skill Slot 5~8 |
| `ESC` | Pause |

## Repository Policy

- 이 Public 저장소에는 Vite production build 결과물만 게시됩니다.
- TypeScript 원본과 개발 문서는 별도의 Private source 저장소에서 관리합니다.
- Public build는 Private source의 `main` 검증 성공 후 자동 갱신됩니다.
- 브라우저에서 실행되는 JavaScript와 공개 에셋은 웹게임 특성상 다운로드 및 분석할 수 있습니다.

외부/AI 에셋과 오디오 출처는 `ASSET_CREDITS.md`, `AUDIO_CREDITS.md`에서 확인할 수 있습니다.
